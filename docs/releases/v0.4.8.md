# Faultline v0.4.8

Faultline v0.4.8 promotes `faultline batch` into the core local diagnosis
surface, refactors the analysis pipeline for clarity, and removes three
low-value companion commands to reduce surface area.

## What This Release Delivers

- **`batch` is now Core** — `faultline batch <file> [file ...]` is part of the
  ship-ready command set for local build matrices and multi-job workflow logs.
- **Stable `batch.v1` contract** — The promotion does not change command
  behavior, exit codes, or JSON schema. Each log is still analyzed
  independently and grouped by failure pattern.
- **Analysis pipeline refactored** — The core analysis path is split into
  `analysis_pipeline.go` and `source_analysis.go` for clarity. External
  behavior is unchanged.
- **Three commands removed** — `signatures`, `verify-determinism`, and
  `compare` are removed. `signatures` duplicated `history` output with no
  marginal value. `verify-determinism` was an internal developer concern, not a
  user-facing feature. `compare` required users to manually manage two saved
  JSON artifacts and was not part of any realistic first-run story.
- **Snapshot-backed smoke coverage** — CLI smoke now checks a checked-in batch
  markdown snapshot alongside the existing JSON schema contract.
- **Test coverage expanded** — New tests for `sourcedetector`, engine delta,
  playbooks, renderer, repo scanner, topology, scoring, and signature packages.

## Release Validation

v0.4.8 should be validated with:

- `make test`
- `make fixture-check`
- `make bayes-check`
- `make review`
- `make docs-check`
- `make cli-smoke`
- `make release-check VERSION=v0.4.8`

## Release Boundary Status

The default user story is now:

- `analyze`
- `batch`
- `workflow`
- `list`
- `explain`
- `fix`

`report`, `history`, `coverage`, `trace`, `replay`, `inspect`, `guard`, and
`packs` remain supported companion surfaces. `signatures`, `verify-determinism`,
and `compare` have been removed. Team-layer sync, auth, hosted aggregation,
dashboards, runtime remote pack fetch, and cross-repo recurrence are out of
scope for this release.
