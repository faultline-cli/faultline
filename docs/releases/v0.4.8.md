# Faultline v0.4.8

Faultline v0.4.8 promotes `faultline batch` into the core local diagnosis
surface for multi-log CI failures.

## What This Release Delivers

- **`batch` is now Core** — `faultline batch <file> [file ...]` is part of the
  ship-ready command set for local build matrices and multi-job workflow logs.
- **Stable `batch.v1` contract** — The promotion does not change command
  behavior, exit codes, or JSON schema. Each log is still analyzed
  independently and grouped by failure pattern.
- **Snapshot-backed smoke coverage** — CLI smoke now checks a checked-in batch
  markdown snapshot alongside the existing JSON schema contract.
- **Boundary preserved** — `report` and `history` remain local recurrence
  companions. `trace`, `replay`, `compare`, `inspect`, `guard`, `coverage`, and
  `packs` remain supported companion surfaces.

## Release Validation

v0.4.8 should be validated with:

- `go test ./internal/cli ./internal/app ./cmd`
- `make cli-smoke`
- `make test`
- `make fixture-check`
- `make bayes-check`
- `make review`
- `make docs-check`
- `make release-check VERSION=v0.4.8`

## Release Boundary Status

The default user story is now:

- `analyze`
- `batch`
- `workflow`
- `list`
- `explain`
- `fix`

Local recurrence and advanced inspection remain outside the first-run story.
