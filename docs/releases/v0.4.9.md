# Faultline v0.4.9

Faultline v0.4.9 continues the command surface reduction started in v0.4.8,
removes unused internal packages, adds new test coverage, and ships a
redesigned README with an animated demo.

## What This Release Delivers

- **Command surface reduced further** — `compare`, `guard`, `history`, `packs`,
  and `trace` are removed. These commands were either internal-concern
  utilities, duplicated information available through core commands, or not
  part of any realistic first-run story. The core surface is now: `analyze`,
  `batch`, `workflow`, `list`, `explain`, `fix`, and `inspect`.
- **Internal packages removed** — The `authoring` (scaffold) and `metrics`
  packages are removed. `authoring` was a dev-only scaffolding helper with no
  user-facing surface. `metrics` duplicated data now served directly by the
  policy and store layers.
- **Policy package** — A new `internal/policy` package consolidates policy
  evaluation logic previously scattered across the app layer.
- **Test coverage expanded** — New tests for fixture commands, input validation,
  and batch output. Coverage increased from 88.8% to 89.1%.
- **Eval corpus tooling** — `tools/eval-corpus` is added as an internal
  evaluation harness for batch corpus runs. It is not part of the shipped CLI
  surface.
- **README redesigned** — Hero animated GIF, inline screenshots for `analyze`,
  `fix`, and `batch`, value-prop bullets at the top, and a restructured
  section layout. Release notes removed from README (they belong in GitHub
  Releases).

## Release Validation

v0.4.9 should be validated with:

- `make test`
- `make fixture-check`
- `make bayes-check`
- `make review`
- `make docs-check`
- `make cli-smoke`
- `make release-check VERSION=v0.4.9`

## Release Boundary Status

The default user story is:

- `analyze`
- `batch`
- `workflow`
- `list`
- `explain`
- `fix`
- `inspect`

`report` remains a supported companion. All other commands (`fixtures *`) are
hidden maintainer utilities.
