# Faultline v0.4.3

Faultline v0.4.3 is a technical-debt and test-framework expansion release.
Six new test-category playbooks land, eight silent-failure playbooks gain
expanded pattern coverage, the renderer and model packages are split into
focused files, and Go test coverage rises to 84.3%.

## What This Release Delivers

- **187 bundled playbooks** (up 6 from v0.4.2's 181).
- **6 new playbooks**: `flexget-test-failure`, `jest-test-failure`,
  `nikola-build-test-failure`, `pip-install-test-failure`,
  `sentry-elasticsearch-test-failure`, and `translate-toolkit-test-failure`.
- **8 silent-failure playbooks with expanded pattern coverage**:
  `artifact-missing`, `cache-miss-non-fatal`, `continue-on-error`,
  `empty-deployment-target`, `empty-quality-check`, `ignored-exit-code`,
  `skipped-critical-step`, and `zero-tests-executed`.
- **3 source playbooks with expanded pattern coverage**:
  `missing-error-propagation`, `panic-in-http-handler`, and
  `unawaited-promise`.
- **Renderer package split**: `internal/renderer/renderer.go` decomposed into
  `renderer_analysis.go`, `renderer_common.go`, `renderer_coverage.go`,
  `renderer_fix.go`, and `renderer_workflow.go` for maintainability.
- **Model package split**: `internal/model/model.go` decomposed into
  `model_analysis.go`, `model_hooks.go`, `model_hypothesis.go`,
  `model_playbook.go`, `model_repo.go`, and `model_workflow.go`.
- **Go test coverage 84.3%** — up from 82.9% in v0.4.2. Coverage gains are
  concentrated in `internal/app` (new service and helper tests),
  `internal/silentdetector` (severity internals), `internal/store` (extra
  tests), `internal/workflow/registry` (steps tests), and
  `internal/authoring` (scaffold test).
- **Top-1 accuracy 1.000** maintained across the full 228-fixture real corpus.
- **Weak-match rate 0.009** unchanged at 2 of 228 fixtures.

## Release Boundary Status

No change to the default shipping narrative. The default user story remains:

- `analyze`
- `workflow`
- `list`
- `explain`
- `fix`

Companion and maintainer surfaces remain supported but non-default:
`inspect`, `guard`, `trace`, `replay`, `compare`, `packs`, and hidden
`fixtures` workflows.

## Remaining Gaps

- **Corpus mix is still GitHub-heavy.** 116 of 228 accepted fixtures are
  GitHub (51%); future ingestion should keep biasing toward GitLab, Stack
  Exchange, Reddit, and Discourse.
- **2 weak-match fixtures remaining.** Targeted `none:` exclusion fixes
  could close these in the next pass.
- **Bayes remains opt-in.** The known Bayes regression on
  `gitlab-gitlab-org-gitlab-runner-6557-s3-64c99cfe7a2f9dfa` is still
  unresolved, so `--bayes` stays outside the default release path.
- **`internal/app` coverage gains continue.** High-integration app-layer
  functions (`WorkflowExplain`, `WorkflowApply`, etc.) still require
  end-to-end wiring for full coverage.
- **`internal/cli` coverage 60.1%.** CLI integration paths need an
  invocation harness; deferred.
