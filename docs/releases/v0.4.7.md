# Faultline v0.4.7

Faultline v0.4.7 is a hardening release for trust, release integrity, and the
local recurrence story. It does not add a new product pillar or change the
first-run narrative.

## What This Release Delivers

- **Stricter release gates** — `make release-check` now includes
  `make bayes-check` and `make docs-check`, so default Bayes ranking drift and
  generated failure-doc drift block release cuts.
- **Script-backed verification aligned** — `make release-verify` runs the same
  Bayes and docs checks before archive smoke validation.
- **Generated failure docs refreshed** — The generated docs for
  `formatting-failure`, `pnpm-lockfile-missing`, `parallelism-conflict`, and
  `testcontainer-startup` were regenerated from the bundled playbooks.
- **Explicit metrics-history input** — `analyze` and `workflow` now accept the
  hidden advanced `--metrics-history <jsonl>` flag. It surfaces the existing
  additive `metrics`, `policy`, `metrics_hints`, and `policy_hints` fields
  only when explicit history data provides enough input.
- **Stable defaults preserved** — Normal `analyze` and `workflow` output stays
  stable unless local history, an explicit store, or explicit metrics history
  is requested.
- **CLI smoke expanded** — Smoke coverage now verifies local `report` output,
  workflow metrics and policy hints, bundled pack provenance, and installed
  extra-pack provenance ordering.
- **Fixture corpus drift corrected** — `docs/fixture-corpus.md` now matches the
  current checked-in baseline: 173 bundled playbooks, 215 accepted real
  fixtures, 100% top-1/top-3 pass rates, and zero weak matches.

## Release Validation

v0.4.7 should be validated with:

- `make test`
- `make fixture-check`
- `make bayes-check`
- `make review`
- `make docs-check`
- `make cli-smoke`
- `make release-check VERSION=v0.4.7`

## Release Boundary Status

No change to the default shipping narrative. The default user story remains:

- `analyze`
- `workflow`
- `list`
- `explain`
- `fix`

`report`, `history`, `batch`, `coverage`, `trace`, `replay`, `compare`,
`inspect`, `guard`, and `packs` remain supported companion surfaces. Team-layer
sync, auth, hosted aggregation, dashboards, runtime remote pack fetch, and
cross-repo recurrence are out of scope for this release.
